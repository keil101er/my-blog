# C 语言对象生命周期与资源管理

**创建对象、准备使用、停止使用、释放对象，是四件不同的事。** C 中需要主动调用相应函数，不会自动执行构造和析构。

## 四类函数分别做什么

以设备对象为例，常见分工如下：

| 函数 | 作用 |
| --- | --- |
| `create` | 分配对象空间，保存配置，返回对象指针 |
| `init` | 配置硬件、准备缓冲区，让设备可以使用 |
| `deinit` | 停止设备，清理使用期间申请的资源 |
| `destroy` | 完成清理，释放创建时分配的对象空间 |

**具体分工由接口约定。** `create` 可以顺便完成初始化，`destroy` 也可以先调用 `deinit`，不要求四个函数都存在。

## deinit 与 destroy 的区别

`deinit` 后，对象可以继续保留，之后重新初始化。

`destroy` 若已释放对象内存，旧指针就不能再使用。因此，不能认为“调用 deinit 就一定会 free 对象”。

对象也不一定由 `malloc` 创建：

- **动态分配的对象**：由约定的销毁函数释放。
- **局部或静态对象**：可以清理内部申请的资源，但不能对对象本身调用 `free`。
- **借用的缓冲区**：按提供方的约定使用和归还，不随意释放。

## 使用时记住三点

1. **失败要处理**：创建返回空指针时不能继续调用；初始化中途失败时，清理已经申请的资源。
2. **状态要明确**：初始化前不能读取未初始化的状态标志；对象释放后不能通过旧指针检查状态或再次释放。
3. **先停用，再释放**：确认 DMA、中断和回调不再访问对象及缓冲区，再释放相应内存。
