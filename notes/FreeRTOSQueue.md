# FreeRTOS 队列：任务通信与队列集

**队列用于任务间传递数据，默认按“队尾发送、队头接收”的顺序工作。** 队列满时发送方可以阻塞等待，队列空时接收方可以阻塞等待。

## 常用函数

| 接口 | 作用与要点 |
| --- | --- |
| `xQueueCreate(length, size)` | 创建队列：最大项数、每项字节数；失败返回 `NULL` |
| `xQueueSend(queue, &data, ticks)` | 向队尾发送，等价于 `xQueueSendToBack()` |
| `xQueueSendToFront(queue, &data, ticks)` | 向队头发送，改变消息接收顺序，不改变任务优先级 |
| `xQueueReceive(queue, &data, ticks)` | 读取并移除队头项 |
| `xQueuePeek(queue, &data, ticks)` | 查看队头项，保留数据 |
| `xQueueOverwrite(queue, &data)` | **仅用于长度为 1 的队列**，保存最新值，没有等待时间参数 |

**发送和接收都要检查返回值，`pdPASS` 表示成功。** `ticks` 是最长阻塞时间，条件满足就立即执行：

- `0`：不等待，无法完成就返回失败。
- `pdMS_TO_TICKS(ms)`：将毫秒转换为 tick。
- `portMAX_DELAY`：`INCLUDE_vTaskSuspend` 为 `1` 时可无限等待。

中断中使用对应的 **`FromISR` 接口**，不能阻塞等待，详见 [普通接口与 FromISR 接口](/notes/FreeRTOSFromISR)。接口定义见 [FreeRTOS 官方 `queue.h`](https://github.com/FreeRTOS/FreeRTOS-Kernel/blob/main/include/queue.h)。

## 按值传递与指针传递

**队列始终按创建时指定的大小复制队列项。** 按值传递复制数据本身，按指针传递只复制地址。

| 方式 | 适用场景 | 关键点 |
| --- | --- | --- |
| 按值传递 | 小数据、固定长度结构体 | 结构体含指针时，不会复制指向的外部数据 |
| 按指针传递 | 大缓冲区、对象池数据块 | 减少复制开销，但要自行管理数据生命周期 |

传指针时，队列项大小设为 `sizeof(DataBlock *)`，发送参数用 **`&ptr`**，接收也传入指针变量的地址。

若约定“发送成功后移交所有权”，需要记住：

- **发送失败：** 数据仍由发送方负责。
- **发送成功：** 发送方停止修改、复用或释放数据。
- **处理完成：** 接收方释放数据，或归还内存池。

不要传出即将失效的局部变量地址，也不要在接收方处理前覆盖原缓冲区。相关概念见 [深浅拷贝](/notes/CObjectStorage#浅拷贝与深拷贝)。

## 队列空满与任务优先级

在**单核抢占调度、一个发送方和一个接收方持续收发**的典型场景下：

| 优先级关系 | 执行过程 | 常见现象 |
| --- | --- | --- |
| 接收方更高 | 发送后唤醒接收方，接收方抢占并取走数据 | 队列容易空 |
| 发送方更高 | 发送方写满后阻塞；接收方取走一项，又唤醒发送方 | 队列容易满 |

**这不是绝对规律**，实际占用量还取决于生产周期、处理耗时和其他任务。

避免高优先级任务以 `0` 等待时间持续忙轮询，否则低优先级任务可能无法运行。使用合适的阻塞等待，让其他任务有机会改变队列状态。

## 多个发送方

多个任务可以共用一个队列。**把“来源标识 + 数据”放在同一个结构体中**，接收方按来源处理即可。

需要保留生成顺序时，可附带序号或时间戳；向队头发送会让新消息排到已有消息前面。

## 一个接收方等待多个队列：队列集

队列集让任务同时等待多个队列。使用前启用 `configUSE_QUEUE_SETS`，基本流程是：

**`xQueueCreateSet()` 创建 → `xQueueAddToSet()` 加入空队列 → `xQueueSelectFromSet()` 等待并取得成员句柄 → 从该成员接收一项数据。**

重点记住三点：

- **容量至少等于所有成员队列的容量之和**，按队列项数计算，不能只按队列个数计算。容量不足可能丢失就绪通知。
- **一次选择对应一次接收**，不要直接读空成员队列，也不要让其他任务绕过队列集消费数据。
- **先判断句柄，再按对应类型接收**，队列集不会自动解析数据。

如果消息可以统一成同一种结构体，优先考虑“来源标识 + 单个队列”。容量说明见 [FreeRTOS 官方队列集教程](https://www.freertos.org/media/2018/161204_Mastering_the_FreeRTOS_Real_Time_Kernel-A_Hands-On_Tutorial_Guide.pdf)。
